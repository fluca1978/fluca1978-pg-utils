* Usage of docker images

In order to use the images:
1) ~sudo docker compose build -d~
2) ~sudo docker compose up -d~
3) check images are running with ~sudo docker ps~
4) attach a console *to the PostgreSQL machine* with:
   ~sudo docker exec --user postgres --workdir /var/lib/postgresql -it $(sudo docker ps -qf "name=pg_database_old")  /usr/bin/zsh~
   or attach a console *to the new PostgreSQL* with;
   ~sudo docker exec --user pgagroal --workdir /pgagroal -it $(sudo docker ps -qf "name=pg_database_new")  /usr/bin/zsh~


* Create the publication

On the old database:
- ~CREATE PUBLICATION to_update FOR ALL TABLES;~
- grant permissions on the ~rsync~ user for the tables and databases.

On the new database:

- ~pg_dump -h pg_database_old  --schema-only -U pgbench -f pgbench.sql -C pgbench~;
- ~create role pgbench with login password 'pgbench';~ or ~pg_dumpall --globals~;
- ~\i pgbench.sql~;
- ~CREATE SUBSCRIPTION updating CONNECTION 'host=pg_database_old user=rsync password=rsync dbname=pgbench' PUBLICATION to_update;~;


* Remove all

1) shutdown with ~sudo docker compose down~
2) remove the ~postgresql~docker~vols~ into the home folder of the admin
